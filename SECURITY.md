# Security reporting

For a vulnerability in the Swift HTTP service, authentication, model loading,
build scripts or dependencies, or for accidental disclosure of private material,
email **research@macbrainslabs.org** with the affected revision, environment,
reproduction steps and likely impact. Do not post exploit details, tokens,
nonpublic weights or personal data in a public issue.

This is an independent research project. Maintained public code is on the
`main` branch; no formal supported-release lifecycle or response SLA is
promised. Security fixes are reviewed and disclosed with appropriate context.
A security policy is not a claim of an external audit or vulnerability-free code.

Normal functionality bugs and documentation corrections may use GitHub issues.
